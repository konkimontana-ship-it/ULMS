# ULMS
# Urafiki Library Management System (ULMS)

## Project Overview
ULMS is a web-based Library Management System developed to simplify library operations and improve the management of books, users, and borrowing activities.

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- XAMPP

## Key Features
- Administrator login and dashboard
- User registration and login
- Book management
- Category management
- User management
- Book issuing and returning
- Book search and filtering
- Database integration

## Installation and Setup

1. Install XAMPP.
2. Copy the ULMS project folder into `C:\xampp\htdocs\`.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Open phpMyAdmin at `http://localhost/phpmyadmin/`.
5. Create the project database.
6. Import the supplied SQL database file.
7. Configure the database connection in the project's configuration file.
8. Open `http://localhost/ULMS/` in your browser.
